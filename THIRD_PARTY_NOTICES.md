# Third-Party Notices & Attribution

This project incorporates architectural patterns and ideas adapted from several open-source projects:

1. **decision-gate** (`zachlandes/decision-gate`, Apache-2.0, Copyright 2026 Zachary Landes)
   - Architectural pattern: Pre-call secret sanitization patterns, TTL-based disk answer caching, and spend budgeting ledger.
2. **jev-style** (`lawrence3699/jev-style`, Apache-2.0, Copyright 2026 chaoliangUNSW)
   - Architectural pattern: Deterministic offline fake server (`fake.py`), normalized confidence calculation (`normalized_pmax`), and safe abstention/escalation.
3. **jev-ultrafast** (`browser-use/jev-ultrafast`, MIT, Copyright 2026 Browser Use)
   - Architectural pattern: Root `AGENTS.md` structure, discrete choice verification, and persistent HTTP/2 connection pooling.
4. **subcento** (`septagos/subcento`, MIT, Copyright 2026 Alterfield)
   - Architectural pattern: Multi-tier pre-flight verification pipeline and pinned model configuration.
5. **oko** (`bartlomein/oko`, MIT, Copyright 2026 Bart Tyrpien)
   - Architectural pattern: Two-stage retrieval gating and strict privacy model (zero source code in telemetry logs).
6. **jev-pruner** (`tamaratran/jev-pruner`, MIT, Copyright 2025 Tamara Tran)
   - Architectural pattern: Chunk-aware command output distillation and local disk spooling of raw diagnostic logs.
7. **jit-context** (`wojciechwiesner/jit-context`, MIT, Copyright 2026 Wojciech Wiesner)
   - Architectural pattern: Paired SWE benchmark methodology with automated pytest verification.
8. **pytest-jev** (`allebee/pytest-jev`, MIT, Copyright 2026 allebee)
   - Architectural pattern: Cache prefix versioning and exponential backoff retry policy on transient HTTP codes.

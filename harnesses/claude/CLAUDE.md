# Laya Agent Kit

Use the `laya-system1-gating` skill when the Laya MCP server is connected. Triage compound requests before broad discovery, audit multi-step plans, filter candidate paths, prefer focused regions for files over 50 lines, distill long diagnostics, triage errors, verify hypotheses, and inspect edits with `verify_patch_state` before running relevant tests. A fallback or unavailable Laya response is indeterminate, not approval. Use Claude Code's native plan and hook mechanisms rather than assuming another harness's features.
